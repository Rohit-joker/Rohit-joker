## 🚀 Flagship Security & Engineering Projects

### 📡 01. Enterprise Network Intrusion Detection & Telemetry Platform
> **Tech Stack:** Suricata IDS · Grafana · Loki · Grafana Alloy · Docker · Python
* Engineered a containerized security monitoring architecture inside an Ubuntu virtual environment.
* Configured **Suricata** in IDS mode to inspect packet payloads and flag anomalous signatures.
* Deployed **Grafana Alloy** for high-throughput log forwarding to **Grafana Loki**, eliminating data drop-off.
* Designed dynamic real-time Grafana security dashboards and set up automated alerting for signature matches.
* 🔗 **Repository:** [View Project Code](https://github.com/rohit-joker)

---

### 🔍 02. Centralized Wazuh SIEM & Threat Log Analysis Lab
> **Tech Stack:** Wazuh SIEM · Syslog · Threat Intelligence · Linux Hardening
* Deployed a centralized Wazuh manager-agent architecture to ingest OSSEC event streams and endpoint logs.
* Simulated real-world attacks (including SSH brute force and unauthorized access attempts) to test correlation rules.
* Configured alert decoders and rule filters to reduce SOC false-positive alerts.
* 🔗 **Repository:** [View Project Code](https://github.com/rohit-joker)

---

### 🚗 03. Edge Vision: Automated Vehicle Plate Detection & Tracking
> **Tech Stack:** YOLOv5 · Deep SORT · OpenCV · Tesseract OCR · PyTorch · MongoDB · React
* Built a deep learning vision pipeline for multi-frame vehicle license tracking in dense urban surveillance feeds.
* Incorporated optical character recognition (OCR) with pre-processing filters for license extraction under low visibility.
* Co-authored and published the implementation research paper.
